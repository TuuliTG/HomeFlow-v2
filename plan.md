# Plan: clearer tasks

Small improvements after trying the task board. **Replace this file when the iteration is done.** Tick steps off
as their PRs merge.

## How we work through it

- One PR per step, on a branch named after the change (ADR 0001). Decisions go into the topic ADRs.

## Steps

- [ ] **1. Descriptions** — an optional description (up to 500 characters) when the title isn't enough, shown on
      the card and editable. Repeating tasks keep it.
- [ ] **2. Taking someone else's task** — marking done a task another member has picked up first asks "Ben has
      picked this up. Mark it done anyway?".
- [ ] **3. Show completed** — a "Show completed" toggle on the task board lists the household's recently done
      tasks, with who did them and when.

## Backlog (not in this iteration)

- Shared family goals and personal rewards (Rewards screen).
- Fewer notifications: batch several new tasks into one, per-user preferences.
- Reuse a previous task when creating one; "last done by …" on cards.
- Leave a household, delete my account (GDPR), password reset by email (needs custom SMTP).
- Child-friendly mode.
